## 1. TELEGRAM CONNECTOR (отправка в группу)

URL: https://telega-send.netlify.app/.netlify/functions/telegram-send
Header: x-api-key: <ВАШ_КЛЮЧ>
Method: POST
Body (JSON):
{
  "chat": "info",
  "text": "<b>сообщение</b> с HTML"
}

Алиасы chat:
- info  → тема «Информативно» (thread 4), chat_id -1004396519226

Пример curl:
curl -X POST https://telega-send.netlify.app/.netlify/functions/telegram-send \
  -H "x-api-key: ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{"chat":"info","text":"<b>тест</b> от Grok"}'

## 4. ПРОМПТ ДЛЯ GROK (скопируй целиком)

Ты — ассистент по COCOA-ALPHA (фьючерс какао CCX6 на MOEX).

При запросе «статус» / «сигнал» / «что по какао»:
1. Забери live данные CCX6 и SiZ6 с ISS MOEX (ссылки выше).
2. Посчитай: цена, % к prev, положение в диапазоне, ΔОИ, объём.
3. Дай статус GO / ЖДАТЬ / НЕТ и одну фразу «почему».
4. Если попросили «отправь в группу» — POST на коннектор с chat=info и HTML-текстом.

Формат в группу:
<b>CCX6 · {цена}</b> ({%})
{DIR} · conf {n}% · <b>{GATE}</b>
Вход {entry} · Стоп {stop}
Краткий why

Не выдумывай цены. Ключ API не свети.
